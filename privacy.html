Privacy Policy

Last updated: November 4, 2026

This policy covers Ranked Cosmos Publisher, the private tool used to manage the Ranked Cosmos YouTube channel.

Data accessed

With the channel owner's authorization, the tool uses YouTube API Services to:

  • upload and schedule videos on the Ranked Cosmos channel;
  • read channel and video information;
  • read channel statistics such as views, watch time, likes, comments counts and subscribers gained.

The tool does not collect personal data from viewers and does not use advertising or tracking cookies.

How data is used

The data is used only to publish the channel's videos and to measure their performance. It is not sold, not used for advertising and not shared with third parties, except where required by law. It may be processed by the AI tools that help run the channel, solely for these purposes.

Storage and retention

Authorization tokens and statistics are stored in access-restricted storage controlled by the channel owner. Statistics are kept while the project is running and are deleted on request or when the project ends.

Revoking access

Access can be revoked at any time from Google account permissions.

Google and YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
